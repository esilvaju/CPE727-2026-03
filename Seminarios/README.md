# Seminários — CPE727: Aprendizado Profundo

Esta pasta reúne os seminários preparados pelos alunos da disciplina **CPE727 — Aprendizado Profundo**, oferecida no contexto do curso de pós-graduação em Inteligência Computacional.

Os seminários têm como objetivo aprofundar e compartilhar temas, métodos e aplicações relacionados ao aprendizado profundo, complementando os tópicos estudados em aula.

## Organização

Cada grupo ou aluno deve criar uma pasta própria para o seminário, usando um nome curto e descritivo. Sempre que possível, organize os materiais da seguinte forma:

```text
Seminarios/
├── README.md
└── tema-do-seminario/
	├── README.md
	├── slides.pdf
    ├── main.tex
    ├── exemplos
    ├──── codigos.ipynb
    ├──── libs.py
    ├──── DockerFile
	└── referencias.bib
```

Os arquivos podem incluir slides, códigos , dados de exemplo e referências. Não inclua dados pessoais, materiais protegidos por direitos autorais ou arquivos grandes que não sejam necessários para compreender o trabalho.

## Conteúdo recomendado

O material de cada seminário deve, quando aplicável:

- apresentar o problema e sua motivação;
- explicar os conceitos e métodos principais;
- discutir aplicações, resultados e limitações;
- incluir referências bibliográficas e links para as fontes;
- identificar claramente os autores e a contribuição de cada integrante.

## Como contribuir

1. Crie uma pasta com um nome curto para o tema.
2. Adicione os materiais do seminário e um `README.md` com uma breve descrição, os autores e as referências.
3. Atualize a tabela desta página com as informações do seminário.
4. Revise os links e confirme que os arquivos podem ser acessados antes de compartilhar as alterações.

> Os seminários são materiais acadêmicos para uso no contexto da disciplina. Cite as fontes utilizadas e respeite as licenças dos conteúdos e dos conjuntos de dados incluídos.
